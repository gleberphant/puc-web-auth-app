Aplicativo de autenticação

Projeto acadêmico de cadastro de usuários, login e autenticação com JWT.

README | Mais sobre o autor

Objetivo

Este projeto foi desenvolvido para as atividades práticas das disciplinas de DevOps e Desenvolvimento Web do curso de Análise e Desenvolvimento de Sistemas da PUC Paraná.

A aplicação demonstra um fluxo completo de gerenciamento de usuários, autenticação e autorização em uma arquitetura com backend e frontend.

Tecnologias

  • Golang no backend e na API HTTP.
  • React e Vite no frontend.
  • JWT para autenticação.
  • Docker para execução do ambiente.
  • SQLite e PostgreSQL como opções de persistência.

Pré-requisitos

  • Golang 1.26.6
  • Node.js 1.24
  • Docker 29.7.2

Execução com Docker

Na raiz do projeto, execute:

docker run -it -p 8080:8080 -p 3000:3000 -p 22:22 \
  -v $(pwd):/app -w /app --name meu-app-dev-run meu-app-dev-image

Como executar

  1. Inicie a API Go na porta 8080.
  2. Inicie o aplicativo React na porta 3000.
  3. Acesse o aplicativo pelo navegador.

Como testar

Os arquivos da pasta test-api descrevem as requisições de cadastro, login, consulta, edição e exclusão de usuários.

Para validar o backend, execute:

cd api-go
go test ./...
